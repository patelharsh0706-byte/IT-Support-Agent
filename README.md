# IT-Support-Agent

An AI IT support agent that resolves employee requests end to end — built with
Next.js (App Router), the Vercel AI SDK, and shadcn/ui.

## Layout

| Path             | Contents                                                    |
| ---------------- | ----------------------------------------------------------- |
| `it-agent/`      | The Next.js application                                     |
| `context/`       | Specs: product overview, architecture, standards, UI, progress |
| `feature-specs/` | Per-feature implementation specs                            |
| `docs/`          | Plans and supporting documentation                          |

`context/` is the source of truth for what to build and how — read
`it-agent/AGENTS.md` first.

## Getting started

```bash
cd it-agent
npm install
npm run dev
```
